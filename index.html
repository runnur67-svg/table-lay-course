사용 방법

① 테이블 카드를 누르고 인원·알레르기를 등록합니다. 등록된 테이블은 착석 전이라도 남은 요리 총량에 포함됩니다.

② 손님 착석과 첫 요리 제공 시 첫 코스 시작을 누릅니다. 이후 요리를 제공할 때마다 서빙 완료를 누릅니다.

③ 상단의 남은 요리는 각 테이블의 아직 제공하지 않은 전체 코스 수량입니다. '지금'은 현재 서빙 시간이 된 수량입니다.

④ 테이블 카드의 노랑은 5분 이내, 빨강은 예정 시각 초과, 초록은 정상입니다. 알레르기는 별도 경고 문구로 표시됩니다.

⑤ 설정 → 공통 코스 구성에서 런치/디너 요리를 편집하고, 회차별 서빙 시간에서 7개 회차의 시작·코스 시간을 따로 지정합니다. 저장하면 현황판에 바로 적용됩니다.

⑥ 상단 타임테이블에서 7개 회차의 표를 열고 PNG 이미지로 저장·공유하거나 인쇄/PDF로 내보낼 수 있습니다. 모든 진행 정보는 이 태블릿의 IndexedDB에 자동 저장됩니다. 인터넷 연결이 없어도 설치 후 이용할 수 있으며, 설정의 전체 데이터 백업으로 JSON 파일을 보관하고 백업 복원으로 복구할 수 있습니다.

중요: 브라우저 데이터 삭제, 앱 삭제 또는 기기 교체 시 데이터가 사라질 수 있습니다. GitHub Pages에는 고객 정보가 저장되지 않으며, 다른 기기로 자동 동기화되지 않습니다.

연습 모드에서는 예시 데이터로 진행을 시험해 볼 수 있으며 실제 데이터는 변경되지 않습니다.
