QUICK GUIDE

사용 방법

① 테이블 카드를 열어 인원·알레르기·오리/와규·굽기·음료를 등록합니다. 현재·다음 요리는 코스를 시작한 테이블의 바로 다음 요리만 합산합니다.

② 착석 완료 → 코스 시작 → 첫 코스 서빙 완료 순서로 누릅니다. 상단 전체 착석 완료는 등록된 테이블의 착석만 일괄 확인합니다.

③ 상단 현재 · 다음은 진행 중인 테이블의 바로 다음 요리만 집계합니다. 메인 코스는 오리·와규를, 마지막 코스는 커피/티 HOT·ICE를 따로 표시합니다.

④ 정상 카드는 차분하게, 5분 이내는 노랑, 지연은 빨강으로 표시합니다. 알레르기가 있을 때만 빨간 안내가 나타납니다. 진행 동그라미는 완료·현재·대기를 나타냅니다.

⑤ 설정 → 공통 코스 구성에서 런치/디너 요리를 편집하고, 회차별 서빙 시간에서 7개 회차의 코스별 실제 서빙 시각을 직접 입력합니다. 저장하면 현황판에 바로 적용됩니다.

⑥ 상단 타임테이블에서 7개 회차의 표를 열고 PNG 이미지로 저장·공유하거나 인쇄/PDF로 내보낼 수 있습니다. Firebase 연동 전에는 이 태블릿에 저장됩니다. Firebase 연동 시에는 인터넷 연결이 필요하며, 연결이 끊기면 실제 운영 변경이 일시 중단됩니다. 설정의 전체 데이터 백업으로 JSON 파일을 보관하고 백업 복원으로 복구할 수 있습니다.

중요: 브라우저 데이터 삭제, 앱 삭제 또는 기기 교체 시 데이터가 사라질 수 있습니다. GitHub Pages에는 고객 정보가 저장되지 않으며, 연동된 태블릿에서는 같은 데이터가 실시간으로 표시됩니다.

연습 모드에서는 예시 데이터로 진행을 시험해 볼 수 있으며 실제 데이터는 변경되지 않습니다.
